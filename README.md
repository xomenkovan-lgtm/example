<h1>Українське сало з часником</h1>
<p>Традиційна закуска з <strong>ніжного свинячого сала</strong> та запашних спецій.</p>

<h2>Інгредієнти</h2>
<ul>
  <li>Сало (зі шкіркою або без) — 500 г</li>
  <li>Часник — <em>5-6 зубчиків</em></li>
  <li>Сіль кам'яна — 2 ст. л.</li>
  <li>Чорний мелений перець — 1 ч. л.</li>
  <li>Духмяні трави (за смаком) — 1 ч. л.</li>
</ul>

<h2>Кроки приготування</h2>
<ol>
  <li>Ретельно промити та обсушити сало паперовим рушником</li>
  <li>Нарізати сало зручними шматочками</li>
  <li>Очистити та дрібно подрібнити або вичавити часник</li>
  <li>Змішати сіль, перець, трави та часник у невеликій ємності</li>
  <li>Добре обтерти кожен шматочок сала отриманою сумішшю</li>
  <li>Загорнути у пергамент та залишити в холодильнику на <strong>2 дні</strong></li>
</ol>
